atlantis check — agreed shape

The check file content is byte-identical to the original. The screen output, the optional CHECKFILE and the exit codes are agreed departures from the original.

Exit codes: 0 no errors, 1 errors found in the orders, 2 the check could not run.

$ atlantis check orders.3 check.3
Checked orders.3 against NewOrigins rules: 2 errors. Result written to check.3
(exit code 1)
(check.3 is replaced if it already exists)

$ atlantis check clean.3 check.3
Checked clean.3 against NewOrigins rules: no errors. Result written to check.3
(exit code 0)

$ atlantis check one.3 check.3
Checked one.3 against NewOrigins rules: 1 error. Result written to check.3
(exit code 1)

$ atlantis check orders.3
(the check result itself, ending in its own "2 errors found!" line — nothing else, so it can be piped)
(exit code 1)

$ atlantis check missing.txt check.3
error: there is no orders file missing.txt
(exit code 2)

$ atlantis check orders.3 /nowhere/check.3
error: could not write /nowhere/check.3
(exit code 2)

$ atlantis check orders.3 check.3          # no game.in in this folder
error: no game.in here to tell which rules to check against. Add --ruleset standard or --ruleset neworigins
(exit code 2)

$ atlantis check orders.3 check.3 --ruleset elves
error: unknown ruleset elves. Use --ruleset standard or --ruleset neworigins
(exit code 2)

$ atlantis check
error: an orders file is required. Try: atlantis check --help
(exit code 2)

$ atlantis check --help
Usage: atlantis check ORDERFILE [CHECKFILE] [--ruleset standard|neworigins]
  Checks an orders file without running a turn. The result (each order echoed back,
  errors marked *** Error: ... ***) goes to CHECKFILE, or to the screen if it is left out.
  The rules come from game.in in this folder unless --ruleset is given.
